## Overview

**PrepWise** is a full-stack AI-powered interview preparation SaaS platform designed to help users:

- Practice technical interviews  
- Analyze resumes using AI  
- Track preparation progress  
- Generate personalized study insights  
- Manage subscription-based access  

Built with a modern React + Node.js stack and designed for scalability, usability, and continuous product iteration.

---

## Key Features

- AI Resume Copilot (ATS analysis + suggestions)
- Analytics dashboard with performance tracking
- Practice session engine with feedback
- SaaS billing integration (Stripe)
- Dark mode support
- Responsive UI across devices
- Authentication & session persistence

## Architecture Overview

Frontend:
- React SPA with routed layout shell
- Component-driven UI architecture
- Tailwind styling + responsive design

Backend:
- Express REST API
- SQLite persistent storage
- Auth + analytics endpoints

AI Layer:
- Resume assistant endpoint
- Prompt-driven analysis system
- Optional external LLM integration

## Run Locally

### Install dependencies
```bash
npm install
```
### Start backend
```bash
npm run dev:server
```
### Start frontend
```bash
npm run dev
```
App runs locally with API proxy enabled.

## Scripts
| Command            | Purpose             |
| ------------------ | ------------------- |
| npm run dev        | Start frontend      |
| npm run dev:server | Start backend       |
| npm run build      | Production build    |
| npm run preview    | Preview build       |
